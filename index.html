~/getting-started

One line, three steps.

3 steps

The loader is a single Luau file. Each script is one line that calls it with a game tag.

01

Open an executor

Ryvora publishes scripts only. You bring the executor, run it, and open the game.

02

Copy a loadstring

Take the line from the game card above. Each script is one loadstring built for its loader tag, for example ("mm2").

03

Paste and run

Paste the line into the executor and run it. The loader fetches the script, and the interface opens in game.

Free and premium.

Free scripts work with a free no-ads key. Premium scripts require a key: win one in a giveaway, buy one, or receive one as a content creator.

Ryvora develops scripts only and does not distribute executors. Use scripts only on accounts you are willing to risk, and follow each game's rules.
